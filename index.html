Mecanica do Sistema

Como o ConcliX opera

Um pipeline de validacao continuo, do repasse do marketplace ao alerta no seu painel.

  1. 01

    Marketplace realiza o repasse

    O marketplace liquida o valor da venda e transmite os dados de pagamento ao lojista. O ConcliX intercepta esse evento em tempo real via integracao de API.

  2. 02

    Consulta ao Bling ERP

    O sistema consulta o Bling ERP para obter o valor de referencia esperado para aquela venda — preco, taxas negociadas e regras de negocio configuradas pelo lojista.

  3. 03

    Validacao cruzada

    O motor de auditoria compara o valor liquidado com o valor esperado. Se o repasse estiver dentro da tolerancia definida, a transacao e marcada como conciliada.

  4. 04

    Alerta automatico de divergencia

    Se houver divergencia (ex: repasse de R$ 1.200 para uma expectativa de R$ 1.500), o sistema classifica a ocorrencia e notifica o lojista imediatamente com o detalhamento completo.

bling-sync.service 
// Sincronizacao com Bling ERP
const referencia = await bling
  .pedidos
  .buscar(pedidoId);

// Calculo do valor esperado
const esperado = calcularLiquido(
  referencia.valorBruto,
  referencia.taxaPlataforma,
  referencia.frete
);

// Validacao de divergencia
if (repasse < esperado) {
  alertas.disparar({
    tipo: 'DIVERGENCIA',
    pedidoId,
    delta: esperado - repasse
  });
}

Integracao Bling ERP

Sincronizacao automatizada com o seu ERP

O ConcliX se conecta diretamente ao Bling ERP para ler os valores de referencia de cada pedido — preco de venda, taxas contratuais com o marketplace e regras de frete — sem necessidade de entrada manual de dados.

  • Conexao via API oficial do Bling — sem intermediarios
  • Regras de negocio gerenciadas no proprio Bling
  • Sincronizacao em tempo real a cada evento de repasse
  • Zero conflito com operacoes ja em curso no ERP
